# 欢迎使用 Melo 🎉

笔记以 `.md` 文件保存在本地，其他 Markdown 编辑器也能打开。这篇指南可以修改或删除。

---

## 🚀 动手试试

- [ ] **剪藏网页**：按 `⌘K` 粘贴文章链接，预览后保存正文、图片和出处
- [ ] **搜索笔记**：按 `⌘K` 搜索“CODE”，找到这篇指南
- [ ] **插入图片**：拖一张本地图片到这里，或直接粘贴截图
- [ ] **插入内容**：在空行输入 `/`，选择标题、表格等内容

部分网页无法完整剪藏，未下载的图片仍需联网查看。

---

## ✍️ 写作与编辑

输入 Markdown，格式随即生效：

- **标题**：行首输入 `## `，创建二级标题
- **列表与引用**：`- ` 创建列表，`> ` 创建引用，`- [ ] ` 创建待办
- **选中文字**：用浮动工具栏加粗、高亮（`==像这样==`）、添加链接或分享为图片
- **调整顺序**：拖动段落左侧的手柄
- **查找与替换**：`⌘F` 查找当前笔记，`⌥⌘F` 查找并替换

---

## 🧩 代码与公式

代码块按语言高亮显示：

```python
def hello(name):
    return f"你好，{name}"
```

公式可以写在行内，如 $E = mc^2$，也可以单独成段。点击公式可编辑：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

## 🔗 笔记链接

输入 `[[`，查找并选择要链接的笔记。

打开顶部的“大纲”，切换到“链接”，查看出链、反向链接和局部关系图。

---

## 🗂️ 笔记和资料，放在一起管理

笔记、PDF、图片、音视频、Office 文档，都可以放进同一个工作区，按自己的习惯整理。

右键文件可重命名、移动或移到废纸篓。

**智能文件夹**按条件查看文件，同一份文件可出现在多个视图中，无需复制。点击旁边的 **＋**，设置条件，预览后创建。多个条件需同时满足，不需要的默认条件可移除。

例如，用 **类型 → 是 → PDF** 集中查看不同文件夹里的 PDF。

> 在智能文件夹中编辑、移动或删除文件，操作的是原文件。删除智能文件夹，只移除视图。

---

## 🔍 搜索标题，也搜索正文

在关键词后加上条件，缩小搜索范围：

- `#melo`：筛选已有 `melo` 标签的笔记
- `kind:pdf`：仅查找 PDF 文件
- `path:Inbox`：仅搜索收件箱目录下的文件

---

## 📤 导出与备份

- **导出**：在顶部点击“导出”，选择 Markdown、HTML 或 PDF。导出 Markdown 不会打包图片
- **备份**：先保存，再复制整个工作区，包括 `.assets` 图片目录和 `.melo` 配置目录。Melo 不提供云同步或自动备份

Melo 围绕 **CODE** 设计：**Collect 收集、Organize 整理、Distill 提炼、Express 表达**。

## ⌨️ 常用快捷键

| 快捷键 | 功能                                  |
| :----- | :------------------------------------ |
| `⌘K`   | 搜索笔记 / 粘贴链接剪藏网页           |
| `⌘N`   | 新建草稿，首次用 `⌘S` 保存后自动保存  |
| `⌘\`   | 展开 / 隐藏侧边栏（焦点不在编辑区时） |
| `⌘,`   | 打开偏好设置                          |

再次打开这篇指南：**帮助 → 使用指南**。

Melo {{appVersion}} · 快捷键以 macOS 为准。
