# Welcome to Melo 🎉

Your notes are local `.md` files that open in other Markdown editors, too. You can edit or delete this guide.

---

## 🚀 Try it out

- [ ] **Save an article:** press `⌘K`, paste a URL, review the preview, and save the text, images, and source
- [ ] **Search your notes:** press `⌘K` and search for “CODE” to find this guide
- [ ] **Add an image:** drag a local image here, or paste a screenshot
- [ ] **Insert content:** type `/` on an empty line and choose a heading, table, or another block

Some pages cannot be clipped in full. Images that did not download still need an internet connection.

---

## ✍️ Write and edit

Markdown formatting appears as you type:

- **Headings:** type `## ` at the start of a line for a level-two heading
- **Lists and quotes:** use `- ` for a list, `> ` for a quote, or `- [ ] ` for a task
- **Format a selection:** use the floating toolbar to apply bold or highlight (`==like this==`), add a link, or share the text as an image
- **Reorder content:** drag the handle to the left of a paragraph
- **Find and replace:** use `⌘F` to find text in the current note, or `⌥⌘F` to find and replace

---

## 🧩 Code and equations

Code blocks use syntax highlighting for the selected language:

```python
def hello(name):
    return f"Hello, {name}"
```

Write equations inline, like $E = mc^2$, or on their own line. Click an equation to edit it:

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

---

## 🔗 Note links

Type `[[` to find an existing note and link to it.

Open the outline from the top toolbar and switch to **Links** to see outgoing links, backlinks, and the local graph.

---

## 🗂️ Keep notes and files together

Notes, PDFs, images, audio, video, and Office documents can all live in the same workspace, organized the way you prefer.

Right-click a file to rename it, move it, or send it to Trash.

**Smart Folders** filter your files. One file can appear in several views without being copied. Click **＋** beside **Smart folders**, set the conditions, and check the preview before creating the view. Every condition must match; remove any defaults you do not need.

For example, use **Kind → is → PDF** to view PDFs from different folders together.

> Editing, moving, or deleting a file in a Smart Folder affects the original. Deleting the Smart Folder itself removes only the view.

---

## 🔍 Search titles and full text

Add filters after your keywords to narrow the results:

- `#melo`: find notes with an existing `melo` tag
- `kind:pdf`: find only PDF files
- `path:Inbox`: search only files in Inbox

---

## 📤 Export and back up

- **Export:** choose **Export** in the top toolbar, then Markdown, HTML, or PDF. Markdown export does not bundle images
- **Back up:** save your changes, then copy the whole workspace, including `.assets` for images and `.melo` for settings. Melo does not provide cloud sync or automatic backups

Melo is built around **CODE: Collect, Organize, Distill, Express**.
