## Smaller download, AI tools when you need them

- Claude Code and Codex are now downloaded when you first connect, instead of being included in every Melo installer. Compatible tools already installed on your computer can be reused.
- Follow download progress in the connection card, cancel and retry interrupted downloads, or close the conversation and let the download continue in the background.
- The first conversation now guides you through connecting an AI tool. Empty conversations offer starting points for reading documents, drafting, and organizing files.

## Clearer updates

- The update window shows distinct states for checking, up-to-date, failed checks, downloading, and ready to restart.
- Read release notes while an update downloads, continue downloading in the background, and choose when to restart.

## Editor and preview refinements

- Click below a document's content to continue writing in a blank paragraph at the end.
- Removed the duplicate file-type label from search previews.
- Web clip properties now use the same captured website icon as the article header.

macOS builds use the same fixed self-signed certificate as 2.0.2 and later. Users on those versions can update from within Melo. **Users on 2.0.1 or earlier must install manually once.** Your notes and workspaces are preserved.

These builds are not notarized by Apple. macOS may require approval in System Settings → Privacy & Security on first launch.
