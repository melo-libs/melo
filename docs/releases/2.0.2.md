## 更新体验

- 更新窗口展示版本说明、下载进度和安装状态；支持稍后更新或忽略此版本。
- 同一个版本只提醒一次，手动检查会复用已有更新窗口。
- 启动 60 秒后检查更新，之后每 24 小时检查一次，可在偏好设置中关闭。
- 下载后校验安装包，支持重试，并保留已下载的可用更新。

本版起 macOS 使用固定自签证书。**2.0.1 及以前版本请手动安装一次**；后续同证书版本可在应用内下载并重启更新。笔记和工作区文件不受影响。

自签证书不等于 Apple notarization，首次打开仍可能需要在「系统设置 → 隐私与安全性」中允许。

## A better update experience

- Read release notes, follow download progress, and install from one update window.
- Update later or ignore a version. Automatic checks won't keep prompting for the same release.
- Check 60 seconds after launch, then every 24 hours. Automatic checks can be turned off in Preferences.
- Downloads are verified before installation. If a download fails, an earlier usable update is kept.

macOS builds now use a consistent self-signed certificate. **If you're on 2.0.1 or earlier, install this version manually once.** Future releases signed with the same certificate can be downloaded and installed by restarting Melo. Your notes and workspaces are unaffected.

These builds are not notarized by Apple. macOS may still require approval in System Settings → Privacy & Security on first launch.
