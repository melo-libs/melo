## More reliable AI connections

- API connection settings now show whether a key has been verified, with clear feedback beside a rejected key.
- New settings use **Verify and save**. Verification happens before saving, so an incorrect replacement key leaves your previous working configuration intact.
- Unchanged verified settings use **Test connection**, which checks the saved configuration without replacing credentials or interrupting the active connection.
- Model discovery and API connection checks now follow your system proxy settings.
- Fixed the connection setup screen briefly appearing before a working AI conversation when opening the window for the first time.

## Update window improvements

- Refined release note spacing and action placement. Once downloading starts, the window focuses on background downloading or installing the update.

macOS builds use the same fixed self-signed certificate as 2.0.2 and later. Users on those versions can update from within Melo. **Users on 2.0.1 or earlier must install manually once.** Your notes and workspaces are preserved.

These builds are not notarized by Apple. macOS may require approval in System Settings → Privacy & Security on first launch.
