## Diagrams and document navigation

- Mermaid code blocks now render as diagrams, with inline zoom and pan, source editing, and **Copy image** / **Copy code** actions.
- Images support inline zoom and pan, reset, and fullscreen viewing.
- A compact contents rail replaces the separate outline sidebar. Hover to browse headings, or press **⌘⌥O / Ctrl+Alt+O** to navigate with the keyboard.
- The footer shows how many notes link to the current document. Click to see all references at the end of the note.

## A more flexible Melo conversation

- Dock the conversation beside your document or pull it back into a floating window. Resize the panel to suit your workspace.
- Attached files take priority when you ask Melo to organize or edit them, and document context changes appear more predictably during ongoing conversations.
- Typing in the conversation composer no longer recreates its size observer on every keystroke.

## Editing and clipping improvements

- Improved rich-text and image copying, preserved formatting when pasting within Melo, and added **Copy as Markdown** with **⇧⌘C / Ctrl+Shift+C**.
- Open document links directly with **⌘-click / Ctrl-click**, with matching cursor feedback.
- Fixed table cell alignment and improved paragraph splitting and undo with the updated editor engine.
- Simplified the web clipping palette, including save actions, capture status, folder selection, and website icons.

macOS builds use the same fixed self-signed certificate as 2.0.2 and later. Users on those versions can update from within Melo. **Users on 2.0.1 or earlier must install manually once.** Your notes and workspaces are preserved.

These builds are not notarized by Apple. macOS may require approval in System Settings → Privacy & Security on first launch.
