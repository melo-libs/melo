## Meet Melo, your workspace assistant

- Ask questions about the document you are reading. Melo follows the active file as you switch tabs, and selected text can be sent directly from the editor.
- Keep a conversation open while you work, or close it to the floating fish. Its appearance shows when Melo is working, waiting for you, or has a new reply.
- Use Claude Code or Codex, with account connections or supported API services. API credentials are stored using this computer's secure storage.

## Organize files through conversation

- Paste or drop attachments into chat to save them to Inbox, then ask Melo to read and organize them.
- Discuss destinations and filenames before applying changes. Managed changes have an undo action that checks for newer edits.
- Ask Melo to update Markdown tags or create and edit Smart Folders using the same metadata and rules as the rest of the app.

## Tags and search

- See document tags above the text and edit them in place, with suggestions from existing workspace tags and automatic saving.
- Hover over a tag to remove it, use keyboard undo and redo, or click its name to find related notes.
- Continue a search in Ask Melo from the Command-K palette, with your question ready to review before sending.
