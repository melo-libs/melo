## Fix installed AI tool detection

- Fixed an issue in 2.1.1 that could show a download prompt even when Claude Code or Codex was already installed. Existing tools are now reused when they can start, without requiring an exact match to Melo's default download version.
- Fixed detection and sign-in checks for npm-installed tools when Melo is opened from Finder, where the Node executable may be missing from PATH.
- Existing tools and account settings are preserved. Connection errors are handled when connecting; newly downloaded files still receive integrity and version checks during installation.

macOS builds use the same fixed self-signed certificate as 2.0.2 and later. Users on those versions can update from within Melo. **Users on 2.0.1 or earlier must install manually once.** Your notes and workspaces are preserved.

These builds are not notarized by Apple. macOS may require approval in System Settings → Privacy & Security on first launch.
