## Fixes

- The macOS application menu now uses the Melo name consistently.
- File context menus no longer repeat the selected filename at the top.
- Pressing Escape in a Smart Folder context menu closes the menu without affecting result navigation.

macOS builds use the same fixed self-signed certificate as 2.0.2. Users on 2.0.2 can update from within Melo. **Users on 2.0.1 or earlier must install manually once.** Your notes and workspaces are unaffected.

These builds are not notarized by Apple. macOS may require approval in System Settings → Privacy & Security on first launch.
